# TrafficVision AI 🚀

- Flask
- Scikit-learn
- Plotly
- Pandas
- SQLite
- Bootstrap

- AI Traffic Forecasting
- Random Forest + Linear Regression
- Interactive Analytics Dashboard
- CSV Upload
- Prediction History
- Export Forecast
- Responsive Dark UI
- AI Charts & Insights
